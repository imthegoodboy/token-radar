A token launch radar: protocols DefiLlama records no token for, ranked by an implied value fitted on protocols that already trade (held-out tested, error stated on the page), each with a costed farm plan, in a static dashboard that needs no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
# open out/dashboard/index.html
node --test test/
```
